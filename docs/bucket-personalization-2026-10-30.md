# Personal bucket icons, covers and photos

Status: verified candidate; production release pending.

Bucket list cards and bucket details now offer Personalize. Users can pick a validated icon, a curated cover or an actual JPEG/PNG/WebP photo, see the selected choices, replace/remove a photo and reset their look. Dashboard bucket thumbnails reflect those choices. Controls follow the existing theme and modal layout, including phone and desktop sizing, loading/errors/retry and archived buckets. Photos are suppressed while money Privacy Mode is on; the editor explains why.

Appearance is personal to this device and scoped to user, household and budget. It stays separate from financial goal fields and canonical financial mutations. Web photos persist as validated Blobs in IndexedDB, not object URLs or base64 preferences; native storage uses the existing persistent filesystem. Old assets are deleted only after a replacement has committed. Scope/revision guards, retry hydration, quota/metadata failures, account deletion cleanup and object URL release protect saved choices. Settled legacy personal plans have a user-specific fallback; unresolved household budgets remain disabled. Cosmetic customization is available to viewers without granting financial write access.

Optional Milestone moments celebrate an explicitly confirmed bucket close or a savings goal reaching its target. Spending the money in a spending bucket never counts as funding a savings goal. Initial/background hydration, failed saves and stale scopes remain silent. Failed saves retain the pre-save baseline so a successful retry can produce the moment. Moments use an accessible modal above the suspended detail underlay, support dismissal/Back and reduced motion, and are recorded once per scoped milestone.
