Run `bash tests/sql/account-forecasts/run.sh` from any directory with a local Docker daemon and a cached official `postgres:17-alpine` image. The runner creates a disposable PostgreSQL 17 container with no network or published ports and removes only that container when finished. It never reads application credentials or connects to a hosted database.

The fixture captures the relevant pre-migration table definitions, policies, financial functions and reconciliation triggers, populated exclusively with fictional households, users, accounts and transactions. The test applies the additive account forecast migration and verifies permissions, household isolation, account identity, CAS retries, atomic mutations and settlement behavior against PostgreSQL itself. Initial financial rows are compared before and after migration to detect backfills or balance changes.

The debt minimum recalculation helper is deliberately a no-op in this fixture: these tests verify routing and authorization, while debt calculation tests run in the application suite. Membership, editor, entitlement and reconciliation predicates reproduce their existing behavior. Provider credentials and provider network calls are absent.
